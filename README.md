# Uzaylı Selamlama Protokolü

## Bu Proje Nedir?

Bu, insanlığın uzaylılarla iletişim kurması için tasarlanmış **en ciddi**, **en abartılı** ve **en çalışan** protokoldür. NASA'nın 50 yıllık araştırmasının özeti burada. Eğer bir uzaylı görürseniz, panik yapmayın, bu scripti çalıştırın.

### Özellikler
- Rastgele uzaylı selamları üretir
- "Çeviri" yapar (asla doğru değil)
- Sonsuz döngüde çalışabilir (dikkat!)
- Gerçekten çalışır, yalan yok

## Nasıl Kullanılır?
```bash
python uzayli_selamla.py
```

Veya:
```python
from uzayli_selamla import selamla
selamla()
```

## Uyarı
Bu protokol, uzaylıların insanlara öfkelenmesine neden olabilir. Sorumluluk size aittir. Kayyum onaylıdır.
